# D8→D2 密集匹配下游：当前实验计划

文档状态：当前规范，2026-10-14 按用户决策确定。架构与基线见[主路线](mainline_d8_d2.md)及[模型架构](model_architecture.md)。原 MHIR P0–P6、E00–E05、TINY-6 与 D1 计划已从工作树移除，历史版本由 Git 追溯。

## 已完成基线

RGB512 H0 联合训练完成 5 epoch、25,535 步，当前登记权重为 `weight/semidense_rgb512_h0joint_from_e_lr8e5_seed42_5ep.pt`。训练只冻结 DINOv3，使用 `Lc+Lf+Lq+Lh0`，5,106 对完整 loss 验证已完成；GoogleEarth 498 对与 JL1Flight 1755 对已完成冻结协议测试。

H0 位置 2×2 固定权重消融也已完成，默认 A 保留。联合监督解决了 H0 头无直接梯度的问题，但尚未证明明显跨域精度提升；H0 位置开关未呈现跨域一致最优结果。两项结果不重新包装为待启动实验，也不根据这些测试结果选择下一版超参。

## 实施顺序

| 顺序 | 工作 | 交付与判断依据 |
| --- | --- | --- |
| 1 | 固定可复用基线 | 新实验登记源权重 SHA、配置、实现、数据清单、种子、输出路径；默认 512/A/4轮QRRU |

| 4 | 做最小机制对照 | 单因素比较候选召回、D2定位、级联起点训练或质量排序；先验证假设，再扩大训练预算 |
| 5 | 验证跨域保留 | 适配训练同时观察旧域和新域；分离共享权重、解码器 BN 统计、匹配头变化，避免只看 JL 提升 |
| 6 | 冻结后正式评价 | 固定权重/超参/清单/评价器后报告各阶段点精度、配准与尾部误差、覆盖、延迟显存及逐对记录 |

每项实验沿[累计研究](research/mhinet_breakthrough/reading_guide.md)保留已有支持与反证，列出足以推翻假设的结果。数据资格或缓存缺件应说明它阻碍哪个对照；候选机制和理论上限不作为已验证性能提升。

## 当前优先核查

1. **D8→D2 可达性与定位。** 区分粗父错误、正确父但窗口覆盖不足、离散标签/mutual 竞争、实际亚像素定位误差；不能仅以粗阶段拟合 H 是否成功判定细阶段上限。
2. **QRRU 与质量排序。** 对相同点集分离坐标更新和边界过滤，核对 GT 噪声训练与真实级联起点差异。保留 QRRU 在合成验证有效的反证，不能把阶段集合 P 下降直接当同点因果。
3. **跨域与全域配准。** 同时看 P/NCM/NM、正确点空间分布、预测 H 的严格 SR 和全域误差尾部；保留旧 JL 适配改善 JL 却损害 GE 的证据。点数截断提高 P 不自动表示配准改善。

## 训练协议

当前 H0 联合配置为[semidense_rgb512_h0_joint_5epoch.json](../configs/semidense_rgb512_h0_joint_5epoch.json)：输入512，seed42，5 epoch，单卡累积8，初始共享/头部 LR 均 `8e-5`，余弦衰减；H0监督权重显式为1，四项分量与训练记录一致。数据为 RGB512 的40,849对 train、5,106对 val；JL 不进入该轮训练。

继续完整恢复使用相同配置与记录的执行策略；更改数据、分辨率、监督或阶段时另注册新任务、建立新优化器。旧 RGB512/JL 配置缺省 H0 字段时，当前训练代码可能启用独立 H0 监督，不能原样启动就宣称严格复现历史 Lc/Lf/Lq。

训练 launcher 与恢复细节见[主路线入口](mainline_d8_d2.md#运行入口)。本次文档整理只确定路线和计划，不产生新训练或测试结果。

## 验收与评价

实现变更验证对应的坐标、匹配、监督梯度或恢复合同；旧 MHIR tiny gate 仅验证旧 H 精修路线。当前验证 loss 衡量 GT 解耦监督，不替代预测级联匹配评价。

正式对照保持相同数据 cohort 与像素单位。至少报告逐对宏平均 P@1/3/5、NCM/NM、预测匹配拟合 H 后的 SR@1/3/5、未封顶全域网格 RMSE 与失败尾部、输出覆盖/失败率、推理延迟和显存。成功对正确匹配 RMSE/失败填10的“论文RMSE”另列，不能替代未封顶配准误差。详细指标契约见[主路线](mainline_d8_d2.md#评价契约)。
