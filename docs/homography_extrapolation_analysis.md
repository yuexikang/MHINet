## 原因

投影形式为 `(u,v) = (h1*x, h2*x)/(h3*x)`。即使H可逆、四角分母同号，当某个角点的分母很接近0时，其投影坐标和局部放大率仍会极大；对H的微小估计误差因此会被放大。

实际生成器`mhinet/dataio/quadrant_tiers.py`约束了凸性、面积、边长、角度、母图内范围、矩阵condition number、分母同号及重叠面积。但它没有限定：

- A→B和B→A的投影分母零线离整个输入矩形必须多远；
- 整幅角点能被外推到多远；
- 相对H在角点或有效区域的局部放大率与各向异性。

两个四边形各自合法、重叠超过50%，不保证A的**非重叠角点**在B坐标中仍接近图像。当前矩阵condition number门槛也不等价于这些几何约束。

## 最严重的实际样本

`past_tier2_1__36.035100129.396223`：

- GT一个角点投影约`(-1039396,2348110)`像素。
- 输入角点离投影分母零线只有0.1916像素（数学上的投影零线，不是图像地平线）。
- GT角点局部最大放大率约1340万。
- 四角MACE为619540.56px，但有效重叠区域平均误差仅1.2503px。
- A/B可见重叠比例约59.6%/87.6%。

这一对贡献了第二档总四角误差的68.1%。GT角点坐标超过10000px的32对（0.83%样本）贡献94.4%。所以236.37px的四角均值不能直接解释为重叠区域对齐差236px。

## 对后续工作的含义

1. 共享描述子训练继续使用GT定义的有效重叠支持；保留旧四角结果，同时以重叠误差、失败率和长尾分位数评价可见区域对齐。
2. 当前第三档仍使用原数据与相同损失，避免中途改变对照；本任务未自动修改数据生产。
3. 下一版数据建议对相对H及其逆添加**尺度归一化**的零线安全距离、角点外推范围、局部Jacobian约束。具体阈值应先统计保留率和几何难度，再固定协议，不为压低当前评估均值事后挑样本。
4. 在启动MHIR全图四角残差训练前，必须处理这种目标定义与可观测范围的不匹配：近投影零线的几十万像素四角残差，不能仅靠改变loss权重解决。可选择新的稳定几何数据协议，或另立实验研究有效支持域控制点；不能直接改既有验证真值。

第一档回测另在卡0运行完整GHIM+CGMDP验证，用于检查第二档是否遗忘；这个外推审计不替代该回测。
