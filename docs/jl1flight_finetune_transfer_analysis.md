# JL1Flight 微调后的跨数据集退化分析

分析日期：2026-10-07；2026-10-08 根据人工确认的错误数据修订。依据完整四组测试的已保存预测、逐对指标与两份完成检查点，不重新训练或推理。

结论：JL 域适配明显提升 JL1Flight，但在当前 GoogleEarth 标签口径下，几何精度退化已发生于 D8 粗匹配，D2 和 QRRU 仅能部分补偿。证据支持训练域变化和系统性几何偏差；具体模块的因果贡献尚未用控制实验隔离。

## 人工确认的数据排除

用户检查后确认 GoogleEarth `googleearth_eval__431` 与 `googleearth_eval__432` 的预测正确，原始影像配对与 GT 错误，要求删去。两对已从原始评测数据、派生 Test_Data 和微调前后两组有效结果中同步剔除；GoogleEarth 由 500 对调整为 498 对。先前两对的极端误差属于错误 GT，不再作为模型错误证据。下面 GoogleEarth 表格和统计均使用剔除后的 498 对。

JL1Flight 仍保留全部 1755 对。用户认为重复纹理使人工检查困难，目前没有确认其 GT 错误，不能依据模型误差大而删去。

- NCM@1/3/5px：在有效支持域内，GT 重投影误差不超过阈值的正确预测点对数量。
- NM：最终返回的全部匹配点对数量。

## 退化位置与几何证据

GoogleEarth：

| 阶段 | P@3px 前→后 | P@5px 前→后 | SR@3px 前→后 |
| --- | ---: | ---: | ---: |
| D8 coarse | 23.96%→17.11% | 51.84%→38.67% | 30.32%→4.62% |
| D2 fine | 33.87%→29.16% | 55.39%→53.72% | 49.20%→7.23% |
| QRRU final | 33.14%→31.09% | 53.18%→55.20% | 49.20%→8.63% |

最终 NCM@5 增加约 273 对/影像对，同时 NCM@1 减少约 366、NCM@3 减少约 227。最终配准 SR@3 的成功数从 245/498 降到 43/498，498 对均输出了匹配并成功拟合 H。源点唯一，不存在重复点膨胀计数。

对每个已拟合 H，在公共 20×20 GT 可见网格上统计：

- 配准网格 RMSE 中位数：3.014→6.922px。
- RANSAC 内点占输出的比例中位数：35.99%→79.37%。
- 所有可投影的最终匹配相对于自身拟合 H 的逐对平均误差，再取跨 pair 中位数：5.332→2.100px。不使用 GT 过滤或仅保留 RANSAC 内点。
- 网格残差平均平移的模长中位数：1.747→2.619px。
- 去除平均平移后的空间残差 RMS 中位数：2.244→6.214px。

这说明微调后预测形成了更一致、但相对现有 GT 有更强位置相关偏差的几何场。P@5 是点级宽阈值正确率；SR@3 是拟合 H 在整个可见网格上的误差判定，二者可以朝不同方向变化。后者也受点的空间分布、错误匹配的几何一致性与外推影响。

after 模型的 fine→final：P@3、P@5 分别提高 1.923、1.485 个百分点，SR@3 从 36/498 到 43/498；299/498 对网格误差改善。QRRU 并非此次整体 SR 下降的唯一来源。NPZ 未保存逐点 fine 坐标，因此这些是各阶段集合的比较，不能当作同一批点的逐点修正实验。

## 训练变化与可疑机制

微调只使用 JL 原训练场景，674 张源影像各有 10 个变换，共 6740 对；5 个 epoch、4215 次更新、初始统一 LR=8e-6。没有混入此前的合成训练集，没有增加辐射增强，只冻结 DINO。

此前合成集覆盖 FLAIR RGB、GoogleEarth current、WHU，包含透视裁剪、弱/强辐射扰动和纹理变化。JL 使用同一原图构造的仿射对，训练多样性和形变类别与跨时相 GoogleEarth 不同。共享 MVT、VGG、解码器和匹配头全部更新，是领域偏移与旧能力遗忘的合理机制；小学习率本身不能避免累计更新造成这种变化。

检查点逐张量对比，按实际组件归属分组（MVT 与 DINO 同处 frozen_dinov3 包装器，不能按包装器名字把 MVT 误判为 DINO）：

| 组件 | 改变张量/总张量 | 相对 L2 变化 |
| --- | ---: | ---: |
| DINO model | 0/278 | 0 |
| H0 head | 0/13 | 0 |
| MVT | 150/151 | 0.4645% |
| VGG（含固定统计） | 48/84 | 0.2772% |
| DeDoDe 参数 | 152/190 | 1.3202% |
| DeDoDe BN buffers（含计数器） | 72/90 | 67.1235%（浮点统计的 L2，计数器不计入范数） |
| QRRU | 18/18 | 1.5522% |

解码器处于 train 模式，只有 VGG BN 统计被固定。解码器 BN 的 running_mean/var 会随 JL 数据更新，其更新不受优化器学习率直接控制。例如 D8 `block1.1.running_var` 的相对 L2 变化为 75.99%。这是需要进一步隔离的重要因素：新域统计可能改变旧域的描述子响应，即使权重梯度更新较小。上述变化率不能单独证明各组件造成了多少精度损失。

H0 头参数相同，仍可能因为输入 MVT context 变化而改变 H0 输出；现有保存预测没有记录 H0，不能独立量化 H0 先验的贡献。

## 解释范围

GoogleEarth GT 描述的是“原始 target/source 名义对齐后添加的合成几何”，并非独立精确测量的原始跨时相配准。431/432 已经人工确认是错误原始配对/GT，而非模型预测失败，并从有效结果中排除；剩余数据也不能仅凭大误差自动判错。因此，上述下降是相对当前有效协议标签的下降，不能直接等同于真实影像配准误差恶化同样幅度。

独立验证具体原因，应在保留开发验证集上比较固定解码器 BN、限制共享描述子更新、JL 与旧数据混合等控制条件；当前分析没有依据 Test_Data 重新选择权重或改训练超参数。

有效证据：`outputs/jl1flight_pre_post_tests_512_20261004/{before,after}_{GoogleEarth,JL1Flight}/{report.json,pairs.jsonl,matches}`；人工排除记录 `outputs/jl1flight_pre_post_tests_512_20261004/googleearth_curation.json`；GoogleEarth 的 `match_index.jsonl` 记录剔除后重编号的 NPZ 与 pair_id 对应关系；训练配置、数据生成说明与两份完整权重。复现展示更新：
