# D2 局部双图调制：模型与实验计划

## 目标和边界

在 `codex/flow-d8-d2` 新增独立实验，改善固定 8×8 目标窗口内的 D2 候选排序。原主线默认配置、模型文件、数据集不变。不更新 Flow、MVT、DINO、VGG、DeDoDe、D8 或温度，不启用 QRRU。不增加真实对应点或遮挡标签。

依据上一轮同点诊断：RGB_512 直接 Flow P@3=87.20%，D2 8×8 软解码=82.38%；窗口有正确候选但选错峰值是主要错误类别。目标是在保留已有上游能力的前提下提升 D2，而非通过减少输出点提高精度。

本模块借鉴用户提供的 CMFE/FiLM 文字，为局部差异条件残差调制；不是对所引论文的复现，也不宣称论文方法已在本任务有效。

## 网络设计

1. 复用旧离散路径置信度最高的 128 个 D8 源父点，用原冻结连续 D8 算法确定目标中心。与前轮诊断同口径，未将主线全局 D8 路径更换成该实验算法。
2. 从最终累加后的 256 维 D2 特征图分别采样 A/B 8×8 上下文，步长原图 2 px，两侧覆盖相同大小区域。原图坐标、bilinear、align_corners=False。无 Flow warp。
3. 使用仅基于图像边界的掩码做窗口均值，绝不使用 H、重叠真值或标签生成调制条件。两侧空间范围相同，但不假设内容完全对应或尺度形变消失。
4. 两侧均从原始特征计算 `s_A=masked_mean(A)`、`s_B=masked_mean(B)`，不能用已调制 A 引导 B。
5. 共享 MLP：`[own, other, abs(own-other)]` 768→64→ReLU→512，最后拆成 gamma、beta，各 256 维。
6. `F'=F + gamma*F + beta`，同窗口所有位置共用通道参数。最后一层权重和偏置零初始化；初始是严格恒等变换。第一步输出层有梯度，隐层从后续步开始学习。没有额外可学习零门控，避免两处同时置零阻断学习。
7. A 只取调制后中心 4×4 的 16 个查询，B 保留 8×8 的 64 个候选。随后逐描述子 L2 归一化、固定温度点积、原双向归一化和局部最高峰周围 3×3 软坐标解码。

输入每侧 `[windows,64,256]`，输出维度不变，参数 82,496。没有空间标量注意力、BN、额外位置先验、Flow 残差输出或候选位移修改。统计使用掩码排除窗口越界位置，目标越界候选也不参与匹配。最终每对最多 128×16=2048 个输出；不添加置信度截断或互选。

## 三组对照

|组|调制条件|训练|
|---|---|---|
|none|恒等映射|无，冻结基线|
|self|`[own,own,0]`|只训练调制 MLP|
|pair|`[own,other,abs(own-other)]`|只训练调制 MLP|

self/pair 相同层结构、参数数量和 seed42。self 的条件不包含另一幅图，因而有效条件自由度较少；不能宣称两组具有完全相同有效表达能力。两组均从恒等映射开始，相同样本顺序和窗口采样、优化预算。

## 数据与初始化

复用 `qrru_corners.selections()` 的 seed42 分层小样本，保持前轮评估可比：

- RGB_512 精确合成 H：254 训练、64 验证、64 测试。
- 杭州真实影像：64 测试，只有最终冻结评估，既不训练也不选 checkpoint。其指标为近似 H 参考一致性。
- 训练与验证来自已存在的 RGB_512 NVMe 缓存；测试来自原 RGB_512 测试目录。实际根目录和逐对 ID 写入 `outputs/d2_modulation/data.json`。
- 已核对 RGB 三个划分之间 pair_id 与 source_path 均无交集。不重新随机划分测试数据、不添加新图像增强，以免改变精确 H 或对照因素。
- 上游权重：`weight/mhi_v2_u0.pt`；下游：`outputs/flow_d8_d2/training/best.pt`（杭州第11轮）。此轮正是在该固定初始化上检验 RGB 训练的局部适配能力，不宣称从头训练或原预训练已覆盖 RGB。

冻结网络只提取一次局部窗口，以 FP32 缓存约 446 对数据，供三组共用。缓存包含用于损失/评估的 H 查询结果，但模型前向只读取特征、边界掩码、候选坐标。缓存不混入已训练的调制输出，原始图像和数据集不写入。

## 监督与训练参数

仅位置分类，不加入坐标回归或几何平滑，以针对排序问题并减少归因变量：

- 精确 H 查询每个 A 源点的 B 目标坐标。
- 在实际 8×8 目标格点上构造四邻域双线性软标签，步长为原图 2 px。
- 只有可见且真值位于有效候选支持范围内的查询参与监督。无标签、不可见、窗口未覆盖的查询忽略；不把它们伪造为严格负样本。
- 损失为软标签加权负 dual-log-probability。64 个候选形成竞争，双向归一化亦提供源查询竞争。不另加难负采样器、dustbin 或可匹配性头。
- 所有点仍参与最终评估；训练忽略不等于推理删除。

|参数|设定|
|---|---|
|优化器|AdamW，lr=1e-3，weight_decay=1e-4|
|训练预算|最多30 epoch，每轮254对|
|每步|1对图像，从固定128父窗口中随机抽64个（最多1024查询）|
|梯度裁剪|全局 norm=1，非有限梯度直接报错|
|调度|CosineAnnealingLR，T_max=30，eta_min=1e-5|
|早停|连续5轮验证 P@3 未提高至少0.1个百分点|
|选模型|RGB 验证全部查询的 P@3；初始恒等模型可作为 best|
|随机种子|模型42；样本/窗口顺序每轮确定且两组相同|
|精度|缓存/MLP/匹配/损失 FP32；冻结提取网络沿用原 AMP|
|设备|GPU0 self，GPU1 pair；不使用已占用的GPU2|

训练进程只加载局部窗口和调制器，不实例化原网络，因此优化器不可能误包含 VGG、Flow 或 MVT。保存 best/last 调制器、配置、逐轮指标；模型体积约0.33MB。停止后加载 best，仅此时评价 RGB test 和杭州 test。无标签在线推理入口为 `model.infer(shared, matcher, adapter)`。

## 验收及解释

实现验收：恒等初始化与基线相似度/坐标完全一致；交换两图顺序时调制对称；越界特征不污染统计；两步后损失可反传到两层 MLP；真实数据跑完训练/验证和 checkpoint 推理加载。与前轮基线核对后再判断收益。

效果同时报告：P@1/3/5/10、原图 EPE、区域正确候选 Rank@1/5/10、输出数、改坏 Flow/救回 Flow 的数量。Rank 分母为有可见正确候选（距离真值≤3px）的查询。P@3 分母为全部输出，不靠删点提高。

- 比 none 更好，只说明局部适配有效。
- pair 比 self 更好，才支持双图条件的额外价值。
- 超过同点 Flow 且净救回为正，才通过“细化优于直接 Flow”的核心验收；未超过必须明确报告。
- 训练与模型选择只用 RGB；杭州结果只作跨域评估。单次seed、小样本结果不升级为最终学术结论。

## 运行

```bash
python -m mhinet.v2.d2_modulation.check
python -m mhinet.v2.d2_modulation.experiment prepare --device cuda:0
python -m mhinet.v2.d2_modulation.experiment train --mode none --device cuda:0
python -m mhinet.v2.d2_modulation.experiment train --mode self --device cuda:0
python -m mhinet.v2.d2_modulation.experiment train --mode pair --device cuda:1
```

输出 `outputs/d2_modulation/{none,self,pair}`。相同输出组目录存在时不覆盖，以免抹去一次试验；新实验使用 `--output` 指定新目录。前处理较慢时可用 `--splits` 只生成指定划分。结果整理到 `reports/d2_modulation`，不把缓存/权重加入 Git。
