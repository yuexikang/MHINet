# Flow → D8 → D2 → 单次QRRU：联合训练设计

状态：连续坐标与单次QRRU联合路径已在mhinet/v2/joint_single实现，两域最终损失反传检查通过。首轮按用户要求在两张卡分别做分域试验，混合域训练尚未执行；实际源查询选择及损失细节见该目录README。现有离散匹配路径保留作基线。所有坐标最终评价为512原图像素；内部转换统一align_corners=False。

## 目标和边界

保留原Flow0+Matchability、DINO/MVT/VGG/多尺度解码器、2×2控制点QRRU拓扑。QRRU只执行一次。DINO冻结；主训练阶段允许MVT、Flow头、VGG、D8/D2解码器、温度和QRRU更新。Matchability仍是可匹配性，不混同于最终定位正确概率，不新建拒配头。

当前代码的联合阶段只保证多个损失共同优化：D8/D2监督窗口来自GT，QRRU候选在no_grad下由离散推理生成。共享MVT特征能收到下游梯度，不等于Flow输出坐标链路已打通。

## 可微匹配链路

对固定源查询a，用Flow位移双线性采样得到目标中心p0=a+Flow(a)。不能把Flow中心round、long或detach后才建立下游窗口。

1. D8：在连续p0周围建立9×9候选（间距8原图像素，半径32px），用grid_sample采样B的D8特征，与A查询特征计算相关性。局部可微匹配概率决定p8。
2. 防止多峰平均：对当前最高峰选择固定局部邻域，在邻域内对logits重新softmax并计算候选坐标期望。峰值索引与候选集合选择不可微；集合内的概率、坐标和采样必须可微。邻域大小先固定3×3，不根据测试集调参。不能宣称离散峰值选择本身可微。
3. D2：保留D8对应下的源端4×4子点。在B端以连续p8为中心建立原4×4局部候选，计算细匹配概率和连续坐标p2。可同样使用峰值邻域解码，避免两个相似目标之间取均值。这里改变了旧版硬D2格点输出，必须单独测无QRRU时的前后差异。
4. 单次QRRU：输入连续a、p2及D2特征，输出四个控制点增量，最终中心p_final=p2+mean(controls)。不再训练多轮轨迹。

几何标签、可见性和正候选集合在no_grad下生成，作为固定监督；传入匹配和QRRU的预测坐标保留计算图。不能让模型通过标签生成路径改变自己的监督目标。

相似度温度保持Tensor，不用float()/item()进入训练计算；可微采样不置于no_grad。可在no_grad中选择源查询索引和固定候选索引，然后从有计算图的张量gather值，不重新构造脱图坐标。

互选、置信度排序、去重和最终2048上限作为候选选择／输出层；训练可用离散索引选出部分样本，梯度仅通过选中值传播。推理的坐标解码与训练完全一致，不采用训练软坐标、推理硬argmax的两套定位规则。

## 各层监督

- D16 Flow：保留有效位置坐标监督及候选位置分类。精确H使用原精确几何目标；杭州位置分类采用已有可信区域、坐标采用带容忍范围的鲁棒损失。
- Matchability：独立使用已有可靠可见性标签。精确合成可由变换和支持域确定；真实近似H的不确定边界不追加严格负例。没有人工变化/遮挡标签，不制造标签。训练不按预测Matchability硬删查询，也不把它当作可学习的定位损失权重，否则可能靠降低分数逃避训练。若用于位置先验强度，首版detach此分支，只由自身损失更新分数；推理阈值另行在验证集校准。
- D8：保留全局/较广范围位置分类辅助监督，防止局部窗没覆盖GT时无法学习找回；增加实际Flow引导窗口内的局部候选分类。GT不在局部支持域时忽略局部正例分类，不把最近候选伪造成正例，也不据此标记无对应。依靠上游Flow与广域位置损失训练找回能力。
- D2：在实际预测D8窗口中监督局部候选分类及连续p2定位；仅当参考真值被局部候选支持域覆盖时使用局部定位监督，避免不可达目标强行拉伸局部解码。对预测窗失败的点单独统计覆盖损失，不在报告中消失。
- QRRU：单次中心损失为主。首版不添加四角直接损失，因为本次0.1权重对照无中心精度收益；四角通过中心及特征采样获得梯度。该决定仅针对新联合路径，旧精确H训练实现不改。

统一定义rho_r(e)=rho(max(||e||2-r,0))；精确H时r=0，杭州r使用现有每对tolerance_px。r是启发式容忍范围，不是测量置信区间。所有新增坐标损失在同一原图像素单位归一化，不能混合D2和原图单位直接相加。旧Flow精确H损失保持原数值定义。

保留每级辅助损失，防止QRRU替上游承担全部定位任务。首版不再加入平滑、循环一致性、几何判别头等额外模块。

## 联合损失和防止改坏

L = L_Flow(含原坐标/分类/Mat权重) + lambda8 L_D8 + lambda2 L_D2 + lambdaQ L_final。

初始建议lambda8=lambda2=lambdaQ=1；这是起始配置，不是已验证最优值。L_D2中的分类和定位分别按有效查询取均值，定位误差按固定像素尺度归一化；记录各项损失和对共享MVT的梯度大小，先做少量真实batch校准，避免数值尺度支配训练。

可选的后续消融为不改坏项：L_safe=max(0,rho_r(e_final)-stopgrad(rho_r(e_D2))-epsilon)。参考基线必须stopgrad，防止通过故意恶化D2降低该项。该约束只描述参考误差，不能保证真实精度逐点提升。首版先不加，避免把单次、连续匹配、联合训练、额外损失同时混成一个无法归因的实验。

精确合成训练保留一定数量高精度实际D2输入和零/小扰动输入，覆盖“应当不动”的情况；杭州不因接近H就强制赋零修正标签，依靠容忍损失处理不确定性。真实预测输入是主路径；GT加扰动仅作为明确隔离的QRRU辅助训练路径，不用于正式验证/测试。

## 初始化和训练阶段

先用RGB_512精确H进行梯度验证和连续定位适配，再混合杭州。训练组内源图与空间块划分沿用既有隔离规则，验证与测试用途固定。

1. 初始化：原Flow权重、刚完成杭州D8/D2的best权重；QRRU全新同种子初始化、末层为零，使初始输出为p2。DINO始终eval/no_grad。
2. 适配阶段建议3轮：先冻结MVT及Flow参数，训练VGG、多尺度解码器、匹配温度和单次QRRU。目的为适应连续坐标解码；保存第0轮D2及最终指标。冻结是暂时参数策略，不在主联合实现中硬写detach。
3. 联合阶段建议最多27轮：解冻MVT和Flow头；初始学习率MVT 1e-5、Flow 1e-5、VGG/解码器2e-5、QRRU及温度8e-5，余弦退火。以等概率交替RGB_512和杭州mini-batch，每域损失先在本域有效标签内归一化，再等权合并，避免标签点数量不同隐式改权重。Batch=1+累积4可沿用，暂不要求大batch。
4. 验证分别报告两个域，先确定共同选优标准再训练，例如两域P@3等权均值；同时记录域内退化与改坏率，不能用单个混合EPE掩盖一域损伤。单模型训练可用早停；若作监督对照则固定相同步数，并同时报告last与best。

上述学习率/轮数为拟定起点，应在真正启动前写入配置；不根据测试结果回调。

## 梯度路径验收

必须分别证明两条路径：

A. 特征路径：L_final → QRRU采样特征 → D2解码器 → VGG/MVT。
B. 坐标路径：L_final → p2 → p8 → p0 → Flow定位头 → MVT。

仅看到MVT有梯度不够，它可能只来自A路径。用单独L_final做一次反传，检查p2/p8/p0及Flow坐标输出、Flow定位解码器参数的梯度，并做小扰动/自动微分方向检查（避开离散峰值切换与容忍区）。刚初始化QRRU末层为零时，其前层梯度可暂时为零；应在两个真实更新后确认前层能收到梯度，不把首步零梯度当故障。

然后分别开启Flow、D8、D2、QRRU损失确认预期参数接收梯度。只做针对这些真实断点的检查，不构造庞大测试/哈希框架。DINO无梯度是明确预期；Matchability的定位权重分支刻意断开也是预期，不能宣称所有分支都接受最终定位梯度。

## 必须报告的结果

报告硬匹配旧基线、新连续匹配但关闭QRRU、新连续匹配+单次QRRU；用相同源查询比较p0、p8、p2、p_final，避免筛选导致伪提升。记录搜索覆盖率、有效查询数、输出点数、P@1/3/5/10、可见EPE、每对正确点数、改坏率、救回率以及推理时延。杭州结果标明近似H参考一致性，RGB_512才是精确H定位评价。训练/验证/测试不能混称。

验收不是“梯度非零即有效”：还必须看到单次QRRU相对同点D2的净收益、改坏率可控，并且Flow原有能力没有明显退化。未满足时保持原Flow→D8→D2为主线。
