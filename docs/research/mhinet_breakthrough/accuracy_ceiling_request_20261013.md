# 下一轮任务：绝对精度上限与大幅提升路线

2026-10-13用户要求：已发表论文精度能到八九十，而MHINet虽然在自己的对比中位居前列，却不到五十；下一次研究应从理论上寻找更大的精度提升。

用户已明确参考：LoRetta的PCK@1/2/3/5=38.7/67.6/81.3/91.4%、AUC83.3%；SwinMatcher可见光precision63.3%、SR100%、RMSE2.831。先读取`paper_reference_clarification_20261013.md`，同时研究点级定位与严格配准，不再只暂定所有参考为SR。当前GE/JL严格SR@3为47.59%/43.65%，排名前列是用户提供背景，不补造外部统一排名。80%–90%是探索目标，不是已证明可达或保证提升。

## A. 先对齐八九十与不到五十

建立指标契约表：论文/版本/发表状态、数据与难度、训练/适配来源、GT、影像尺度、误差阈值、分母、失败处理、宏/微平均、输出预算、配准模型与估计器。

LoRetta用户数字已核验，PCK在RANSAC+TPS所得512密集warp的完全可匹配GT像素上统计，AUC为其PCK曲线积分。当前SR@3按影像对统计预测H在GT可见20×20网格RMSE≤3px；P@3是返回匹配上的逐对宏平均。SwinMatcher论文已定位，用户数值的具体表/成功与RMSE定义仍需核。它们不能直接相减作为算法差距，但不能停在“口径不同”，要继续推导同协议真实提升路线。[LoRetta v1 §V-A及表III](https://arxiv.org/html/2608.04106v1)

若同数据、同协议所有方法均只有约50%，优先解释数据难度、标签/目标模型和共同泛化不足；若强基线在同协议达到80%–90%，再定位MHINet独有缺口。两种情况都要继续研究真实提升，指标核对不是把低精度解释掉的终点。

## B. 定义理论上限，不把oracle当成性能

1. **数学评分可达性与图像可辨识性分开。** 现评分GT本身是H，属于拟合模型族；直接使用GT H会得到零评分残差，是定义内的理想值，不证明模型从真实跨时相内容可辨识该H。GE原生残差、变化区、重复纹理和局部非单应几何仍未知。标签可信度需要独立证据，不能用模型自己重新标注。
2. **分解每个限制环节。** 分析预测支持域漏掉多少稳定对应、GT对应能否进入fine候选、错父能否补救、严格定位误差/系统偏差、错误对应与最终质量排序、双侧覆盖与几何退化、拟合采样/重拟合误差、训练域缺口和跨域遗忘。区分哪些是该环节的条件上限、哪些下游可以补救；不将coarse/fine/final宏平均P简单相乘充当SR。
3. **恢复范围要用初始残差。** 现QRRU四轮中心每轴位移严格小于12输入px，只是输出可达盒，不是稳定收敛半径。令fine初始残差为Δ，宽松可恢复误差下界为`d_min = sqrt(max(|Δx|-12,0)^2 + max(|Δy|-12,0)^2)`。若d_min>τ，该点在当前结构下无法进入τ像素圈；d_min≤τ也不保证可学习或收敛。这是512坐标下的必要条件，不直接等于整对SR上限，其他正确点仍可能估出H。不能由最终NPZ反推fine初始可达性，也不能把D2离散候选间距当作整个系统的不可突破精度下限。
4. **偏差、随机噪声、几何条件分开。** 在明确的小误差线性化、可辨识和误差模型假设下，推导点数/独立有效点数、位置分布、误差协方差对H参数及可见网格误差的影响；点增加可能降低方差，但共同偏差和相关错误不会因密集输出自动消失。检查两侧覆盖、Jacobian条件数与误差相关，而不是只数NCM或RANSAC内点。
5. **GT辅助对照只作诊断。** 在隔离开发集规划固定候选的oracle质量选择、理想支持域、理想父对应/定位及拟合对照，分别检验选择、覆盖、恢复和估计的可改善空间。oracle可能是诊断参照或限定的经验包络，不自动是严格全局上界；GT不进入正式推理或候选筛选。缺少完整开发缓存时先给符号/条件推导与最小采集方案，不阻塞整轮或改用测试选方案。

若使用RANSAC命中概率`1-(1-w^4)^N`，明确四点均匀抽样、有效正确集合、非退化空间跨度、实际独立尝试数等假设；有限池无放回四点的全正确概率应按组合数算。GT阈值P不等于拟合器共识比例，10000上限不等于实际尝试数，且有全正确样本不保证最终H达到SR@3。结合14/16时旧审计，不用理想公式直接许诺80%–90%。

## C. 与旧证据结合的高收益候选

- **数据及域适配：**补齐等尺度、双向部分重叠和真实跨时相，保留多域数据；旧JL微调P@5=92.65%、SR@3=72.36%说明现架构有较高域内表现，但GE SR@3降到8.63%，所以目标是严格配准与跨域保留共同提高，而不是只得到一个宽阈值高数字。证据见`docs/jl1flight_finetune_transfer_analysis.md`。
- **真实预测起点精修：**冻结上游后用实际预测训练refiner，可直接对照当前GT噪声任务；RoMa v2 v3 §3.3采用这一机制。若错父/候选不可达占主导，先改候选召回而非盲目增加QRRU轮数。[RoMa v2 v3](https://arxiv.org/html/2511.15706v3)
- **严格定位与几何一致性：**区分离散候选选择、局部相关亚像素精修、可辨识全局H/局部残差以及直接配准监督。模型族改变必须有独立真实GT与公平协议支持，不通过更换评价模型制造提升。
- **质量与空间联合选择：**结合既有点数课题，学会拒绝真正无对应/错误候选、更新QRRU后置信度、维持全域覆盖；不能把全部无fine标签当负例。固定K与随机/空间均匀对照用来区分选择收益和数量效应，已保存旧分数校准诊断可成为子证据。
- **优化与容量：**先隔离共享梯度、decoder BN和遗忘，再决定分组优化/轻量适配或新结构；不是简单堆参数。密集12000点和QRRU在小型合成验证能高精度的反证必须保留。

理论解释、现有实证支持、待验证假设及预期收益的不确定性分别写明。不能预填“某项提高20–30个百分点”，也不能将各项假想增益相加。只给有证据支持的优先级与支持/否定标准。
