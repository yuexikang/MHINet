# MHINet 第一轮突破研究

日期：2026-10-12，Asia/Shanghai。当前结论：**最有证据支撑的突破候选是补齐真实任务的数据分布，并让 fine/QRRU 学习真实上游预测的误差；同时控制跨域遗忘和最终匹配质量。** 已定位问题并制定可证伪实验，还没有通过新训练证明精度提升。

本轮并行审计了数据和逐对预测、现行模型与训练、10篇一手可核验论文；新增统计仅使用 CPU。没有改变现有模型、训练配置、数据和权重，没有启动 GPU 或训练。

## 1. 当前基线与实际任务

主线是半密集 RGB512：冻结 LoRetta/DINO，MVT/GHIM-H0→VGG/CGMDP→D8粗匹配→D2细匹配→4轮QRRU。D4是累计解码中间尺度，不是独立的匹配阶段；早期 README 的6次MHIR更新不是当前系统。

H0 joint 从E组初始化，40,849训练对、5,106验证对、5 epoch、25,535步。新旧RGB512还存在单/双卡、BN和RNG历程等差异，因此不能把当前结果当作严格H0单因素消融。

| --- | ---: | ---: | ---: | ---: |
| GE 498对，新H0 joint | 8.249% | 33.245% | 53.425% | 47.590% |
| GE 498对，旧RGB512 | 8.243% | 33.142% | 53.176% | 49.197% |
| JL 1755对，新H0 joint | 7.100% | 37.924% | 59.507% | 43.647% |
| JL 1755对，旧RGB512 | 7.289% | 38.615% | 59.883% | 43.875% |

来源：`outputs/semidense_rgb512_h0joint_test512_20261012/comparison.json`及对应逐对JSONL。精度为逐对宏平均；阈值以存储影像512目标像素为单位。SR@3由预测匹配拟合H之后的可见网格RMSE≤3px决定，不等于至少20个正确匹配的旧success定义。

当前材料不足以重新建立所有外部方法的公平排名；本轮聚焦绝对精度受限的机制。历史合成2000对E模型P@1≈99.64%与这里的真实任务不可直接比较为方法退步，但显示仅看合成成绩不能代表真实迁移能力。

## 2. 优先突破方向

| 顺序/维度 | 已确认的证据 | 下一项最小验证 | 因果结论何时成立 |
| --- | --- | --- | --- |
| 前置：数据/评价可靠性 | GE GT只描述原生跨时相图像上新增的几何，原生对齐残差未知；FLAIR仅证明文件隔离，未证明地理隔离 | 检查开发来源/footprint；预先抽独立稳定地物点，估计标注重复性和原生残差 | 需要独立标签与严格分组；不能按当前模型的错误删样本或生成自证GT |
| 1：数据几何覆盖 | 训练B overlap恒1；中心等效尺度中位1.612，无尺度<1；只有105/40849（0.257%）在JL约0.8–1.2范围 | 固定开发影像做方向/尺度审计；独立消融交换A/B、等尺度和双向部分重叠 | 同预算、同来源，只改几何采样，在隔离开发集稳定提高精度与SR并保留其他域 |
| 2：方法/训练输入分布 | fine用GT D8父对应；QRRU用GT中心加σ0.8、界±2.4 D2小噪声；推理都接预测 | 固定同点lineage，保存fine起点和每轮更新，分初始误差、错父对应、纹理与置信度 | 先证明真实输入独有的退化，再单因素比较真实预测起点与GT噪声训练 |
| 3：模型最终质量判断 | QRRU后confidence沿用fine分数，只剔除非有限/越界中心；默认阈值0 | 检查预测置信度校准、空间覆盖、保持原点和每轮输出，明确拒绝与精修各自作用 | 在固定点数/空间预算下P、NCM及SR共同改善；不能靠大量丢点虚增P |
| 4：训练跨域保留 | 旧JL微调JL P@5=92.655%、SR@3=72.365%，GE SR@3却49.197%→8.635% | 先拆分参数与decoder BN buffers；随后分别验证固定BN、多域混合和只训精修 | 需要控制BN、初始权重、数据量和步数，兼顾JL和跨时相开发panel |
| 5：多任务优化 | 25535步全局裁剪均触发；epoch1 GHIM头梯度平方占比中位81.83%，epoch5为9.56% | 测不同loss对同一共享参数的梯度范数/方向和实际更新，再单因素改分组LR/裁剪 | 小loss不代表梯度小；现有日志未证明冲突，必须以真实级联开发精度验证 |
| 后续：精修结构/骨干 | D2离散候选、4×4局部特征；缺少显式局部cost volume和更新后质量头 | 同起点比较局部相关亚像素头；只有候选覆盖与输入分布修复后才做D1/新骨干探针 | 同预算多个开发域一致获益，不能依据外部论文成绩直接更换骨干 |

顺序1与2可以并行研究；前置标签/分组审计贯穿所有实验。这里的排序是当前证据下的研究优先级，未被验证为实际收益排名。

## 3. 最直接的证据链

当前JL fine→final：P@1/3/5由7.624/40.913/62.565%下降至7.100/37.924/59.507%，其中1653/1755对P@5下降。SR@3只增加14对。GE的P@3/5也下降，P@1却改善，所以不能概括为QRRU在任何任务都无效。

完整合成val的GT噪声任务QRRU EPE从2.0008px降至0.1514px；8对固定合成val真实级联也从fine P@1=38.09%升至final97.06%。这削弱了“QRRU普遍实现错误”的解释，却强化了真实域/起点分布差异的研究价值。已有最终NPZ缺少完整fine起点，当前阶段对比不是严格同点因果实验。

[RoMa v2 §3.3](https://arxiv.org/html/2511.15706v2) 明确冻结已训练matcher，并用inference实际输出训练refiners。这是与本项目问题最直接对应的论文机制。建议先保持现有QRRU结构、冻结shared/coarse/fine，单独验证“真实fine候选+小噪声混合起点”的训练方式；不可恢复错父对应应先区分拒绝/保持任务，不能全部强行回归。

H0的能力传递也需要重新理解：D8仅使用H0生成overlap支持；fine窗口为`H0(a_k)+coarse_target-H0(coarse_source)`，其中仿射H0的平移严格抵消。提高H0全局定位不会自动修复错的D8父单元。应先分解support和局部形变的贡献，再决定增加H0监督或连通梯度。

## 4. 论文给出的可迁移路线

本轮核验10篇：LoRetta、RoMa v2、LoMa、Who Handles Orientation、MatchAnything、MINIMA、Efficient LoFTR、LiftFeat、XFeat、RoMa-Ω。包含2026-09公开工作；不声称穷尽全部最新文献。公开/发表状态和版本见专题报告。

- **真实预测训练精修：**[RoMa v2](https://arxiv.org/html/2511.15706v2)，与当前GT加噪声起点形成明确差异；先迁移训练机制，保持结构对照。
- **多域同时混合与保留：**[MatchAnything](https://arxiv.org/html/2501.07556v1)，为多域混合而非持续单域覆盖提供正文消融依据；BN因素需单独隔离。
- **可见与可对应分离：**[LoRetta](https://arxiv.org/html/2608.04106v1)，支持研究变化区域、no-match及matchability，而不是把几何overlap等同内容可对应。
- **独立GT与数据质量：**[LoMa](https://arxiv.org/html/2604.04931v2)，提醒数据与标签配方可在已有架构上产生增益；本项目需先量化真实GT不确定度。
- **局部亚像素对照：**[Efficient LoFTR](https://arxiv.org/html/2403.04765v1)，提供离散定位后小窗相关的精修机制；本项目D2插值是否含足够信息仍需测试。
- **骨干后置：**[RoMa-Ω](https://arxiv.org/html/2609.09507v1) 的新骨干只列长期候选；应先做同预算探针并确认权重可用，不能复制论文大训练规模。

## 5. 评价目标与研究边界

同时追踪P@1/3/5、NCM、匹配点数、空间覆盖、预测H的全对网格RMSE分布、SR、失败率、速度与内存。JL当前全对网格RMSE中位3.367px、P95=102.456px、均值16.004px；文档paper RMSE=6.791px是正确子集/失败常数的条件指标，不能描述这一长尾。

开发集应由RGB512严格区域留出、JL train-only条带留出和独立跨时相开发影像组成。先核查与已观察测试的来源/地理重叠，再冻结panel。JL五变换共享351个base，应按base/区域聚类bootstrap，不能把1755对作为完全独立场景。新方案按开发指标预先选择，正式结论需锁定后新的封存测试集。

后续最小实验一次改变一个因素，同初始权重、数据来源/量、有效batch、BN行为、预算和选择规则。真实预测起点训练、数据几何补齐、质量头、多域混合和优化器变更不能一次全加后声称各自有效。若只让loss降低、P升而NCM/SR跌，或只改善单域却显著遗忘，不称突破。

## 6. 下一小时的具体任务

先核查现有开发集预测中是否保存完整fine起点与lineage；列清可以直接重建的内容和缺失字段。利用已有数据做CPU可完成的误差/覆盖/训练噪声范围分析，设计最小“同点fine→每轮QRRU”开发诊断的样本、字段与否定标准。若关键数据尚未生成，记录明确的最小推理方案与预计资源，继续可独立推进的几何方向/验证地理隔离核查，不反复把同一假设写成新发现。
