## 3．条件上限与历史判断更新

评分GT属于H模型族，直接使用GT H可得零网格残差；数学评分上限与真实图像可辨识性分开。原生残差、变化区及重复纹理可能限制可学习对应，目前缺独立证据，不能用模型错误自证标签错误。

H0支持决定哪些查询进入级联；fine以预测父窗口展开16子格，仿射H0平移在残差格中抵消，不能自动修复错父。四轮QRRU解析中心位移每轴小于12输入px。对fine起点残差Δ，宽松必要边界为

`d_min = sqrt((|Δx|-12)_+² + (|Δy|-12)_+²)`。

固定候选且不丢点时，d_min>τ的点无法进入τ圈；界内不保证收敛。最终NPZ不能反推这一初始可达率。D2离散格也不是不可突破定位下限：合成反证已显示亚像素精修可有效。[当前fine格]( /home/disk1/MHINet/mhinet/downstream/supervision.py:64)、[QRRU更新]( /home/disk1/MHINet/mhinet/downstream/qrru.py:51)

条件于正确共识、小误差、固定权重及rank(J)=8，令点误差为共同偏差b加零均值噪声η，`M=(JᵀWJ)⁻¹JᵀW`，G为评分网格Jacobian，则

`E[RMSE_grid²] ≈ ||GMb||²/m + tr(GM Cov(η) MᵀGᵀ)/m`。

独立噪声与充分覆盖才使增点降低方差；共同偏差、相关错误及空间退化不会因12000点自动消失。数学反例：所有对应都偏移4px，可有P@5=100%且H自洽，却严格SR@3失败。RANSAC错误共识不满足上述线性假设，10000上限亦非实际独立尝试数，不能据理想命中概率承诺高SR。

## 4．最多三个大幅提升候选

1. **有旧域保留的目标域适配：幅度证据最强、成本最高。**旧JL适配P@5=92.65%、SR@3=72.36%，同时GE SR降至8.63%，说明有域内改善空间和遗忘风险；训练尺度/重叠缺口仍相关。最小单因素为同权重、样本预算、步数及BN策略，对照JL-only与预注册旧域replay比例，只改来源混合；BN冻结另做。若隔离开发上JL严格定位/SR与旧域保留不能共同改善，否定该配方。[迁移证据]( /home/disk1/MHINet/docs/jl1flight_finetune_transfer_analysis.md:51)
2. **真实fine起点训练现有QRRU：成本中等。**RoMa v2《Harder Better Faster Denser Feature Matching》（Johan Edstedt等；2025，v3为2026-07-06）§3.3冻结matcher，以真实预测训练refiner。本项目先冻结上游参数及buffers，仅改变GT噪声/实际fine起点，结构、半径、损失及预算不变；分可恢复、错父不可达与内容无对应，全量评价。若同点P@1/EPE与NCM/SR无联合收益或跨域退化，削弱此路线；不盲目增轮或扩大半径。[v3原文](https://arxiv.org/html/2511.15706v3#S3.SS3)
3. **最终质量与空间选择：成本最低，大幅收益证据较弱。**旧分数能粗排但不能消除共同偏差。隔离开发固定池、候选ID、K及拟合契约，仅改变top-K、随机、置信分层随机、空间均衡规则，另设排列对照；K示例256/512/1000/2000/4000/全部只在开发确定。共同报告P@1/3/5、NCM、NM、双侧覆盖、SR、失败率及网格RMSE分位数。仅P涨而覆盖/NCM/SR降是权衡；同K规则无SR和尾部收益则否定大幅提升解释。缓存筛点收益不代表fine推理加速。

上述均为候选，没有收益百分点可相加。GT oracle只作诊断，方案锁定后才使用新封存测试。合格开发缓存、WHU地理映射与独立真实GT继续待外部证据，不再占整轮。
