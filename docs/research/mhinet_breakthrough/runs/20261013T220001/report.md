JL首Q4合法2999点，残差均值(−2.444,+2.303)，中位数(−2.409,+2.389)，不是少数极端点独自拉动。源块9有407个Q4点、均值(−2.064,+2.045)，块10有225点、(−2.954,+2.916)，块14有338点、(−3.671,+3.691)；后两块全部点中的错误共识分别998/1109、975/1030。块13旧分数均值0.72749，仍有747/1254点处于错误共识。这支持空间相关定位偏差，不能仅靠旧分数大判真。

## 5．最多三条候选及否证
1. **真实fine起点精修，优先定位。**冻结上游参数/buffers，结构、损失和预算不变，只对照现有GT噪声起点与真实预测起点；按来源/地理组隔离开发。若同点P@1/EPE、全量NCM和严格SR不能共同改善，削弱路线。RoMa v2《Harder Better Faster Denser Feature Matching》（Edstedt等，2025；本轮核验2026-07-06 v3）§3.3提供真实预测起点及独立残差不确定性机制。([arxiv.org](https://arxiv.org/html/2511.15706v3))
2. **质量—空间选择，成本最低但幅度未知。**固定候选池/ID/K，比较旧分数top-K、随机、分数分层随机及双侧空间均衡，固定拟合契约并另设排列对照。若只P升而NCM/覆盖/SR降，判为权衡；随机和均衡都无稳定严格SR/尾部收益，削弱数量/布局突破解释。残差质量头另作单因素，不与删点或训练改动捆绑。RoMa v3区分overlap和二维残差精度，但零均值协方差不能替代系统偏差校正。([arxiv.org](https://arxiv.org/html/2511.15706v3))
3. **带旧域保留的适配，幅度历史证据最强、成本最高。**同预算只改来源replay，BN策略固定且另实验；若JL严格定位改善伴随GE继续严重遗忘，不称跨域突破。EMA暂不升级独立路线：RoMa描述约0.1px/640的训练波动，本轮2–数px、位置相关残差不能据此认定同因。([arxiv.org](https://arxiv.org/html/2511.15706v3))

各路线共同报告P@1/3/5、NCM、NM、双侧覆盖、SR、失败率及网格RMSE分位数；开发锁定后用新封存测试。合格缓存、独立GT、Swin原表继续待外部证据，不阻止下一轮读取既存阶段H。**供findings收录：固定四样本存在不同几何误差结构；高分和广布H共识仍可系统偏离GT，单纯降点数或统一平移均无已验证收益。**
