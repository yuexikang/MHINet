# C/D 第三档计时重测结果（2026-09-28 汇总）

按用户要求，旧C/D测试目录、日志和比较页已删除，原路径已由此次完整计时测试覆盖。两组各2000对、同一manifest及pair_id顺序，预测失败率均为0。测试为独立同母图合成第三档，不代表真实跨时相配准精度。

## 计时边界

独立入口 scripts/evaluate_semidense_timed.py，计时器 scripts/semidense_timing.py。未修改 mhinet/downstream 或特征网络实现，因此E训练恢复哈希不受影响。每次仅处理一对影像；显式预热、读图、预处理、CPU到GPU传输、GT评估、绘图和写盘不计入。CUDA event记录非重叠区间，结束时同步；包含CPU提交间隙，不能解释成纯CUDA kernel执行时间。QRRU区间包括描述子投影、迭代与输出整理。

两组第一对影像都通过计时前后预测坐标/置信度逐位一致校验；所有逐对模块耗时非负、分解误差为0。CPU单测3项通过：分布、耗时记账、异常后方法恢复。
