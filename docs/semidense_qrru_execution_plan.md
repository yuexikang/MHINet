# 半密集下游与 QRRU 最终执行计划

日期：2026-09-22。状态：设计确定，待实现。本文不是已完成实现或精度验证的记录。

## 1. 目标和固定边界

加载第一阶段 GHIM/CGMDP checkpoint，建立第二阶段 D8 coarse → D2 fine → QRRU 半密集匹配。第二阶段损失仅为 `lambda_c * Lc + lambda_f * Lf + lambda_q * Lq`，不加载 GHIM/InfoNCE 辅助损失，不经过 MHIR，不计算 D1。

当前运行中的训练保持原入口和配置。先独立实现、验证新下游；第一阶段 checkpoint 就绪后，记录路径、格式和 SHA，再用于第二阶段。新输出和优化器状态独立，不把第一阶段优化器当作第二阶段恢复状态。

H0 的直接用途只有：

1. 推理时预测双侧重叠支持区，限制 coarse 候选。
2. fine 阶段构造 H 投影加 coarse 残差的局部采样窗口。

QRRU 不接收 H0，不使用 H-warped 网格或上游 H0 掩码。它只接收 D2 特征、fine 对应点及独立的图像有效性信息。H0 可通过上游对应点间接影响 QRRU 初始化。GT 单应仅供训练监督，不是推理输入。

## 2. 特征和坐标契约

- 输入图像：784×784。D8：`[B,2,256,98,98]`；D2：`[B,2,256,392,392]`。
- D4 仍参与 CGMDP 累计解码，但不直接进入匹配头。
- coarse/fine 几何接口沿用 `align_corners=False` 归一化坐标。
- QRRU 位移统一用目标图 D2 像素单位；从 D2 像素转归一化采样坐标时分别使用宽高。
- 原图坐标：`x=(u+0.5)*W_native/392-0.5`，`y=(v+0.5)*H_native/392-0.5`。A/B 分别传入原始尺寸；若以后有裁剪或 padding，额外逆变换。
- QRRU 输出连续坐标，不要求生成 D1。连续输出不等于已验证的亚像素准确率。

## 3. 训练监督与推理

训练时三个监督分支用 GT 解耦，求和后一次 backward：

```text
D8 → coarse 分数 ← GT coarse 标签 → Lc
D2 → fine 分数   ← GT coarse 锚点 → Lf
D2 → QRRU        ← GT fine 中心 + 扰动 → Lq
```

GT 构造、候选索引和初始窗口坐标可在 no_grad 下生成；描述子相关性、特征采样、QRRU 的循环更新保留计算图。QRRU 的后续采样位置对累计流场可微，循环中不默认 detach 隐藏状态或流场。

推理严格使用预测 coarse → 预测 fine → QRRU，无 GT 候选补充。训练和推理入口分开，不能通过是否存在某个 GT 字段隐式切换。

### 3.1 Coarse：D8

沿用归一化描述子的 cosine/temperature，不额外混入 `1/sqrt(C)`。可学习温度采用正值参数化。由 H_gt、双侧有效区和双向几何检查生成稀疏正对应索引，明确格点舍入、边界及多对一消歧规则。

`Pc = softmax_row(Sc) * softmax_col(Sc)`。

`Lc = mean[-(1-Pc_positive)^2 * log(Pc_positive)]`。

损失计算在硬筛选前；GT 标签不需要完整稠密矩阵。训练使用有效图像支持，避免预测 H0 mask 删除正样本；推理使用预测支持。记录这一支持区差异及 coarse 召回。

全 D8 相关约 9224 万元素/图像对，使用可反向的分块与重计算策略；实测反向峰值内存，不能只按推理分块内存估算。

### 3.2 Fine：D2

采用现有 P6 H-warped 4×4 几何语义。训练使用 GT coarse 锚点 `(a8,b8)`，推理使用预测 coarse 锚点。A 窗口是 coarse 格子的 16 个 D2 子点 p_i；B 窗口为：

`r8 = b8 - project(H0,a8)`

`q_i = project(H0,p_i) + r8`。

两侧 D2 窗口做 16×16 全相关、dual-softmax；不能强制同索引对应。GT 标签由 H_gt 投影与实际 B 采样位置匹配，明确距离容差、双向检查和重复消歧，不能把形变窗口当成规则像素网格直接取整。

`Lf = mean[-(1-Pf_positive)^2 * log(Pf_positive)]`。

记录有效正样本数、窗口几何覆盖率、无正样本窗口比例。无有效监督时返回与特征连接的零损失并记录原因；不得伪造正标签。H0 非法时 fine 分支安全跳过，coarse/QRRU 的独立训练不因此全失效。

### 3.3 QRRU

D2 经共享 `1×1 Conv 256→48`。对中心对应 `(af,bf)`，两侧均用规则 4×4 偏移 `{-1.5,-0.5,0.5,1.5}`：

`GA(i)=af+delta_i`；`GB0(i)=bf+delta_i`。

训练 `bf=project(H_gt,af)+epsilon`；推理 bf 来自 fine。训练 GT 映射须先统一到对应 D2 坐标系。扰动尺度和截断界按 D2 像素登记，覆盖合理 fine 初始化误差。

网络：

- WA/WB：`[M,48,4,4]`，隐藏状态：`[M,32,4,4]`，初始为零。
- 拼接 128 通道 → Conv3×3 128→64 + 通道 LayerNorm + GELU。
- DWConv3×3 + Conv1×1 64→32 + GELU → 轻量门控隐藏状态。
- Conv2×2 stride2 32→32 → 1×1 head 32→32→3。
- 两通道位移、一通道更新门控；门控不是已校准的匹配置信度。

`U0=0`

`Ut=U(t-1)+sigmoid(g_t)*r*tanh(delta_t)`

`GBt=GB0+I(Ut)`。

每轮从完整 B 特征图重新采样，不对上一轮的小窗口反复插值。四控制位移在迭代中不平均；最终取控制场中心值读取对应中心。

控制点位于四象限中心 `(-1,-1),(1,-1),(-1,1),(1,1)`。实现显式双线性控制基函数，按实际位置向外延拓至 4×4 外圈；不能用边界钳制插值偷偷改变控制点语义。每控制分量的更新受 r 限制，但外圈延拓位移可能超过 r，测试和统计需区分这两者。

相对固定初始网格定义累计 GT：

`Ugt_k=project(H_gt,af+delta_k)-(bf_init+delta_k)`。

`Lq_control=sum_t gamma^(T-t) * mean_valid Charbonnier(Ut-Ugt)`。

加入每轮中心坐标监督作为 Lq 内部项，目标为 `project(H_gt,af)`，约束实际最终读取位置；分别记录 control/center 数值。有效性依据 GT、源/目标有效区确定，不能用预测是否出界来丢弃困难样本。预测出界仍保留有效 GT 的坐标监督并记录采样失效。

平滑损失作为默认关闭的可选消融。QRRU 不通过自身更新门控加权监督，避免靠减小门控逃避损失。

输出 `bf_final=bf_init+I(UT)(center)`，并与 af 一起转换为原图坐标。保留 coarse/fine 置信度和位移诊断；不把更新门控直接乘进最终匹配分数。

## 4. 参数更新与初始配置

第一版冻结 DINOv3、MVT、GHIM 预测头，训练 VGG、CGMDP 累计解码器、匹配温度、D2→48 投影和 QRRU。不调用会默认解冻 MVT/GHIM 的 configure 后直接沿用其参数组；新增显式参数策略及梯度审计。

后续解冻 MVT 是独立实验，因为它同时影响 H0 与 CGMDP 上下文。冻结 GHIM/MVT 需同时检查模块训练模式，不能只看 requires_grad。

初始工程配置：QRRU T=4、r=1.5 D2像素、gamma=0.8；损失权重先显式设为 1/1/1，Lq 内控制与中心项分别归一化、权重各1；coarse/fine 温度从当前 cosine 约定的0.05开始。QRRU 训练扰动以0.8 D2像素标准差的截断高斯起步，截断至每轴±2.4。以上是待工程验证的起点，不宣称最优，不照搬贴文温度或损失权重。

训练/推理匹配数上限、训练窗口采样预算和分块大小单独配置，按有效样本数归一化损失。使用现有 train/val 划分，测试集不用于超参数选择。

## 6. 验收关卡

### G1 几何与接口

- D8→D2子点与原实现一致；D2/native坐标往返覆盖不同A/B尺寸、非方形图。
- H残差fine网格正确，H0非法时无非法求逆/采样传播。
- QRRU API不含H0；固定D2和初始对应时改变外部H0不改变QRRU结果。
- 零流恢复规则初始窗口；平移、缩放、剪切验证四控制场及中心读出；透视情形报告插值近似误差。

### G2 损失与梯度

- 小型相关矩阵的分块值/梯度与完整计算一致。
- Lc回传D8，Lf回传D2；Lf不经过coarse预测选择，但可通过累计解码更新共享上游参数。
- Lq更新投影、QRRU和CGMDP；冻结参数无梯度。检查至少两个优化步，避免零初始化首步造成误判。
- 空有效集、边界、非法H0与极端logit均无NaN。GT窗口坐标no_grad不切断特征梯度。
- 训练/推理均支持batch内变长对应列表；按窗口块计算而不复制整幅特征M次。

### G3 集成

- 小样本训练分别记录三项loss，QRRU逐轮控制误差/中心误差和前后误差，不能只凭总loss下降通过。
- 记录coarse召回、fine GT覆盖率、预测fine精度、QRRU出界率及更新幅度。
- 完整推理不接受GT；检查输入文件和模型调用路径。
- checkpoint重放及优化器边界恢复通过；测量forward/backward显存与稳定计时。

### G4 下游效果

同一共享checkpoint、数据划分和评价口径，对比 coarse-only、fine-only、fine+QRRU；同时保留原P3/P6参考结果。登记原图precision/NCM/EPE、失败率、空间覆盖及QRRU前后误差分布。匹配拟合H误差作为独立指标，不混用H0误差或旧正确点条件RMSE。

G1–G3完成后才启动正式第二阶段训练；第一阶段权重尚未就绪时可先使用明确标注的兼容权重进行工程验证。G4结论以验证集结果为准，工程通过不等同精度提升。
