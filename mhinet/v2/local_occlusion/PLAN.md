# MHINet v2：D16 Flow0 监督与局部遮挡实验方案

## 一、实验目标与研究边界

本轮仅研究 **DINOv3 → MVT → D16 Flow0**，不运行、不修改 D8、D2、QRRU。

主要研究三个问题：

1. 随机局部遮挡能否使网络学会区分可匹配与无对应区域，而不损害未遮挡区域的定位精度？
2. 为什么增强区域分类后，正确候选排名改善，但 Flow-P@3 下降？
3. 能否在保留 B/C 减少严重错配能力的同时，恢复或超过 U 的精细定位能力？

固定输入512×512，D16为32×32，每对图像有1024个查询位置。冻结 DINOv3，训练预训练 MVT 与 Flow Head。暂不更改原有网络主干。

## 二、已有实验结论

以第30轮同口径结果为基线：

| 模型 | EPE ↓ | P@3 ↑ | Rank@1 ↑ | EPE>32 px ↓ |
|---|---:|---:|---:|---:|
| U | 11.39 | **68.81%** | 88.09% | 4.63% |
| B | 10.67 | 66.19% | 89.95% | 3.77% |
| C | **10.50** | 66.25% | **90.17%** | **3.26%** |

现阶段不直接将 C 作为最佳模型。

既有实验说明预训练定位器微调是主要收益来源；区域分类和难负样本监督进一步减少严重错误，但没有同时提升3 px以内的预测比例。

原 C 使用整张 B 全黑，固定空图探针的 dustbin Top1 为100%。该结果尚不能证明实际部分遮挡场景下的拒绝匹配能力。

## 三、实验阶段一：既有模型的诊断

此阶段不重新训练。

### 3.1 连续坐标解码误差归因

加载 U/B/C 的第30轮权重，对完全相同的验证查询保存：

- 参考目标坐标；
- Flow Head 连续预测坐标；
- 相似度最高的候选及其概率；
- 正区域排名、正区域概率总质量；
- Top-K 候选的坐标分布和概率熵；
- 目标点距图像边界的距离。

按以下条件分别统计 EPE 和 P@3：

| 条件 | 目的 |
|---|---|
| 正区域 Rank@1=1 | 判定正确粗候选下的 Decoder 误差 |
| Rank@1>1 | 判定候选匹配错误 |
| 正候选概率≥0.9 | 查找高置信大误差 |
| 距边界0–8 / 8–16 / 16–32 / >32 px | 判断边界偏差 |
| EPE≤3 / 3–8 / 8–32 / >32 px | 分析误差转移 |

对高置信但 EPE>8 px的点，额外保存坐标偏差方向和局部图像。

重点核查 G1 中正确区域概率约0.902、EPE约22.51 px的案例，以及 G3 中正确候选概率约0.944、EPE约34.42 px的案例。

同时构造 GT 引导的理想位置概率分布输入原 Decoder，测试其在近似理想候选输入条件下的定位偏差。该诊断只用于分析，不用于推理。

### 3.2 G3 灾难性样本审计

固定检查：

- `val_G3_12add035b2b2190ad8b131b2`
- `val_G3_a4e0a479df8364b40227e2c5`
- `val_G3_d675c8471dc323c373c41661`

逐对检查参考 H、有效掩膜、实际重叠区域、Top-K候选、预测位移与图像尺度旋转信息。

区分以下情况：

- 真值参考有问题；
- 正确对应存在，但全局候选未检索到；
- 候选正确，但解码错误；
- 对应实际不可靠或不可观察。

这些样本仍保留在正式全量统计中，另附去掉上述3对的诊断统计，不利用验证集异常样本重新筛选训练集。

## 四、实验阶段二：局部随机遮挡负例

### 4.1 数据制作方式

每对正常训练影像保留原始 A、B，同时构造一对带局部遮挡的训练输入。

初始遮挡策略：

| 参数 | 初始设置 |
|---|---|
| 遮挡位置 | 优先 B 图 |
| 遮挡数量 | 1个矩形/影像对 |
| 遮挡面积 | 原图的5%–20%，分层随机 |
| 矩形长宽比 | 0.5–2.0 |
| 填充值 | 50%全黑、50%全白 |
| 随机位置 | 图内随机，兼顾实际重叠区域 |
| 遮挡边界 | 允许边界，但必须记录实际面积 |
| 随机性 | 根据 seed、pair_id、epoch 固定生成 |

像素填充值使用预处理前RGB空间中的0或255，不直接对已归一化特征填入0或1。

第一轮只遮挡 B，避免同时改变源查询与目标候选两侧的可观测性。后续再做 A/B 对称遮挡消融。

如果采样的矩形没有覆盖足够多的可信对应位置，应重采样或跳过本次遮挡监督，并记录原因。不能为了获得负例而扩大近似 H 的可信范围。

### 4.2 三类标签

需要显式划分 Positive、Negative、Ignore。

**Positive：**

A 图查询可见，且其在 B 图的可信对应区域完全位于遮挡矩形之外。继续使用正常的候选分类、Matchability 和有效坐标监督。

**Negative：**

A 图查询可见，但其在 B 图的整个可信对应区域被人工遮挡。此时修改后的图像对没有可观察的目标对应，监督 dustbin 与低 Matchability。

**Ignore：**

可信对应区域与矩形只有部分交集，或者原始近似 H / mask 不足以确认对应关系。不强行赋正负标签。

设遮挡区域为 \(R_B\)，参考对应为 \(H(x_i)\)，不确定性区域为 \(\mathcal U_i\)。

\[
N_i=1\quad\text{当}\quad \mathcal U_i\subseteq R_B
\]

\[
P_i=1\quad\text{当}\quad \mathcal U_i\cap R_B=\varnothing
\]

其余标记为 Ignore。

实际计算需考虑原始 `known/visible`、`soft_radius_B_px`、D16单元尺度和边缘缓冲。只有原始可观察且监督可信的查询可以转化为人工遮挡负例。

**禁止把所有位于黑白矩形附近的查询直接设为 no-match。**

### 4.3 损失设计

遮挡负例损失：

\[
L_{\mathrm{occ}}=
-\frac{1}{|N|}\sum_{i\in N}\log P_{i,\varnothing}
-\lambda_m\frac{1}{|N|}\sum_{i\in N}\log(1-m_i)
\]

其中 \(P_{i,\varnothing}\) 为 dustbin 概率，\(m_i\) 为 Matchability。

对遮挡后仍可匹配的正查询，保留正区域分类损失：

\[
L_{\mathrm{keep}}=
-\frac{1}{|P|}\sum_{i\in P}
\log\sum_{j\in\mathcal P_i}P_{ij}
\]

训练总目标：

\[
L=L_{\mathrm{clean}}+
\lambda_{\mathrm{occ}}L_{\mathrm{occ}}+
\lambda_{\mathrm{keep}}L_{\mathrm{keep}}
\]

原始未遮挡影像对继续使用所属基线的原损失，防止模型只学习拒绝匹配。

遮挡负查询不计算 Flow Geo Loss；遮挡边缘不确定查询忽略。

新增损失按有效查询数量分别归一化，并记录各项对 MVT 和 Flow Head 的梯度范数，避免新增损失通过数量优势主导优化。

## 五、阶段二消融实验矩阵

| 编号 | 原始监督 | 人工负例 | 研究目的 |
|---|---|---|---|
| U | 原 Flow Loss | 无 | 精定位基线 |
| B | 区域分类+难负样本 | 无 | 当前分类增强基线 |
| C | 同 B | 整图全黑 B | 原拒绝匹配基线 |
| N1 | 同 U | 局部遮挡 B | 单独验证局部负例价值 |
| N2 | 同 B | 局部遮挡 B | 验证分类增强与遮挡互补性 |
| N3 | 同 B | 局部遮挡 A/B | 验证双向遮挡是否更好 |

优先执行 N1、N2。只有 N2 能证明有效后，再开展 N3。

A 图遮挡时，位于完全遮挡单元内的 A 查询可以监督为不可匹配；部分覆盖单元仍标记 Ignore。未遮挡的 A 查询继续学习正常对应。

训练设置保持30 epoch、相同初始化、种子、训练样本清单、优化器及学习率。

对于新增增强前向，比较组必须使用相同的增强输入序列和训练更新预算。应同时报告实际前向次数与计算量；不能把增加训练计算量得到的收益全部归因于负例策略。

## 六、阶段二评价

### 6.1 原始图像评价

保持现有64对清洁验证集不变，记录：

- Flow-P@1/3/5/10；
- EPE（有效点加权）；
- EPE>8/16/32；
- Rank@1/5/10；
- G0/G1/G2/G3 分组指标；
- 真实查询的 Matchability 和 dustbin 误拒绝比例。

### 6.2 局部遮挡评价

在同一64对验证集上，使用独立固定种子生成遮挡版本，不使用训练时的随机掩膜。

统计：

| 指标 | 含义 |
|---|---|
| Negative Dustbin Top1 | 人工遮挡负查询拒绝成功率 |
| Negative Matchability | 负查询的可匹配度分布 |
| Positive False Reject | 未遮挡正查询被错误拒绝的比例 |
| Positive Flow-P@3 | 未遮挡正查询定位精度 |
| Boundary Error | 遮挡矩形周边查询的误差 |
| Matchability AUROC | 对人工可匹配/不可匹配查询的区分能力 |

另外按遮挡面积5%、10%、20%分别评价，测试黑色与白色之间的泛化。

可再设置灰色块或图像内容覆盖作为未见过的诊断条件，判断模型是否仅记住黑白块外观。

这部分仍然只验证人工遮挡鲁棒性，不直接宣称真实遮挡或真实非重叠检测能力。

## 七、实验阶段三：精细定位恢复

只有阶段一确认正确候选与连续坐标解码之间存在系统性误差后，才改动 Decoder。

首选两项相互独立的研究：

**方案 R1：保持现有 Decoder，增加可信精确几何训练。**

使用单张源影像生成具有精确 H 的两幅变换图像，保留真实浮点坐标映射。通过不同旋转、缩放、平移和辐射扰动训练连续 Flow 回归。

精确数据承担小误差坐标回归，杭州近似 H 数据主要承担外观变化与区域匹配监督。两类数据分别计算损失，不把近似地理 H 伪装成精确 Flow。

**方案 R2：改进概率分布到坐标的解码。**

比较旧 MatchEmbeddingDecoder 与基于候选概率的连续坐标估计，包括局部概率加权坐标和可学习残差预测。

重点验证正确候选已经具有很高概率，但旧 Decoder 输出明显偏移的样本。

需要注意，D16间隔为16 px，粗格候选坐标不能仅通过硬 Top1 达到3 px精度。必须保留连续坐标估计能力。

R1、R2分开实施，不能同一次实验同时修改训练数据、损失和 Decoder，再把全部收益归因于某一个模块。

## 八、结果验收及停止条件

本轮以 **Flow-P@3 为主要精度指标**，其他指标衡量鲁棒性和位置判别能力。

局部遮挡实验是否保留，应至少满足：

1. 人工负查询拒绝能力明显优于所属无增强基线。
2. 清洁图像 P@3 相比所属基线下降不超过预登记容差，建议先以0.5个百分点作为诊断门槛。
3. 未遮挡正查询的误拒绝率不显著增加。
4. G1/G3 不出现新的大幅精度退化。
5. 严重大误差比例不明显增加。

如果仅提高局部遮挡拒绝率，但清洁 P@3 明显下降，则保留为独立鲁棒性分支，不并入主线。

如果 R1/R2 能在保留 B/C 的低长尾错误比例基础上，达到或超过 U 的 Flow-P@3，则作为下一版 Flow0 候选。

最终必须另设未参与选模的测试数据，并至少复核额外随机种子，不能只凭当前64对验证集选择最终方法。

## 九、Codex 执行要求

在 `codex/d16-correspondence-ablation` 基础上建立新实验分支，不覆盖既有 U/B/C 结果。

优先完成阶段一的诊断脚本和阶段二的数据、标签、损失单元测试，再运行 N1/N2。输出完整的实验配置、模型初始化身份、逐轮 CSV、配对验证结果和可视化。

局部遮挡可视化至少包含原始 A/B、修改后的影像、Positive/Negative/Ignore 掩膜、dustbin 概率图、Matchability 图及有效查询的 Flow 残差图。

整个过程严格限制于 D16 Flow0，不引入 H0 预测头，不修改后续匹配与精修模块。
