# MHINet：Partial Correspondence Flow0 实验计划（PCF-01）

## 1. 实验目标

在不破坏现有 U0 坐标预测能力的基础上，建立具有显式 No-Match 决策的 D16 Flow0。

当前模型固定为：

- 输入：`[B, 2, 3, 512, 512]`
- Backbone：DINOv3 + MVT
- 查询分辨率：32×32，共 1024 个查询
- 全局匹配分布：`[B, 1024, 1025]`，包含 1024 个空间类别及一个 Dustbin
- 原始坐标模块：MatchEmbeddingDecoder
- U0 权重：Epoch 30
- D8/D2/QRRU：完全不参与本轮实验

### 1.1 最终模型行为

对 A 图每个查询，允许以下结果：

| 状态 | 含义 | 是否输出有效坐标 |
|---|---|---|
| MATCH | 判断存在对应，接受匹配候选 | 是 |
| NO_MATCH | 判断不存在可观测对应 | 否 |
| UNCERTAIN | 证据不足，暂不接受该匹配 | 否 |

`UNCERTAIN` 不代表真实无对应，也不应被训练成 Dustbin 真值。

### 1.2 三个验收目标

1. **拒配能力**：在确定不存在对应的位置，模型能够输出 NO_MATCH。
2. **定位保持**：在真实对应区域，原有 Flow 坐标精度不下降。
3. **输出稳定性**：错误匹配不能仅凭高 Matchability 就成为有效输出；同时避免把 G0/G3 中真实存在但预测困难的对应误判成 NO_MATCH。

本轮不使用 D8/D2/QRRU 精度决定实验结果。

## 3. 阶段 A：冻结 U0，定位 No-Match 的真实失效类型

### A1. 模型与数据

完全冻结 U0，不增加任何参数。

使用以下四类数据：

| 数据类型 | 正例 | 负例 | 主要作用 |
|---|---|---|---|
| 精确合成全重叠 | 已知几何对应 | 无或少量 | 保持定位精度 |
| 精确合成部分重叠 | 重叠区域 | 几何图外区域 | 检查几何拒配 |
| 真实纹理合成遮挡 | 未被遮挡的对应 | 人工确定遮挡位置 | 检查视觉拒配 |
| 杭州 G0–G3 | 近似 H 可评价查询 | 不提供真实遮挡负标签 | 分析高置信参考错配 |

杭州仅作为参考定位诊断，不生成新的真实无对应标签。

### A2. 需要导出的逐查询数据

每个查询保存：

- `source_xy`
- `gt_target_xy`，仅真实位置标签已知时存在
- `pred_target_xy`
- `gt_state`：MATCH / NO_MATCH / UNKNOWN
- `p_dustbin`
- `p_spatial_max`
- `dustbin_logit_margin`
- `matchability`
- `spatial_entropy`
- `top1_top2_margin`
- `epe_px`，仅有真实对应时计算
- `pair_id`、数据类型、原始影像来源

Dustbin Margin 定义：

\[
\Delta_i=z_{i,\varnothing}-\max_j s_{ij}
\]

其中 \(z_{i,\varnothing}\) 是原始 Dustbin Logit。

同时保存 Dustbin Top-1 判别结果。

### A3. 必须进行的诊断

**诊断 1：几何非重叠**

检查 Dustbin、Matchability 是否都能够识别投影到图外的位置。

**诊断 2：真实纹理遮挡**

与已有黑白矩形测试分开统计。重点检查具有正常 RGB 纹理、但不属于同一地表对象的位置。

**诊断 3：有对应但错误定位**

在杭州 G0/G3 中筛选：

- Matchability ≥0.9；
- 参考 EPE >32px。

检查 Dustbin 是否仍然认为存在对应。

这类样本不能直接用于 No-Match 训练，因为参考位置错误并不等于真实对应不存在。

**诊断 4：两类输出是否矛盾**

检查是否出现：

- Dustbin Top-1，但 Matchability 很高。
- Dustbin 概率很低，但 Matchability 也很低。
- Matchability 很高，但空间分布多峰或定位错误。

### A4. 阶段 A 的判断

如果 U0 已经能以较低误拒率识别所有确定无对应类型，则不训练新分类头。

如果仅在人工遮挡或重复纹理型无对应中失效，则进入阶段 B，重点针对这类困难负例训练。

## 4. 阶段 B：构造真正具有无对应关系的数据

### B1. 数据来源

优先使用现有高分辨率遥感 RGB 母图。

要求母图能够支持两个 512×512 裁剪窗口，且已知裁剪之间的精确几何关系。

对于同源合成样本，几何标签由生成参数计算，不使用跨时相近似 H 作为精确真值。

### B2. 几何部分重叠数据

从同一母图生成 A、B：

- 统一输出 512×512；
- 重叠率分层为 20%、40%、60%、80%；
- 随机平移；
- 随机尺度变化；
- 旋转覆盖 0°–15°，包含 6°–12° 困难范围；
- 保存精确 A→B 和 B→A 变换及有效裁剪掩膜。

重叠率以真实有效图像区域计算，不以裁剪框外接矩形的粗略交并比替代。

**非重叠区域保留真实影像纹理，不能直接填充黑色。**

### B3. 真实纹理遮挡数据

在具有精确对应的合成图对上，修改 B 图局部区域。

建议使用另一幅独立母图中的真实纹理块覆盖目标区域：

- 覆盖面积：5%–20%；
- 覆盖位置：随机，包含重叠区域内的对应目标；
- 覆盖内容：道路、建筑、植被、裸地等真实纹理；
- 不使用纯黑、纯白填充作为主要训练数据。

对原本落在被覆盖区域的 A 图查询，若其完整查询支持范围被覆盖，则标记为 NO_MATCH。

未被遮挡的位置继续保持 MATCH。

边界附近标记为 UNKNOWN，不参与分类损失。

对于 B→A 方向，来自外部母图的覆盖纹理也应视为无真实几何对应。

注意：这种方式只能模拟确定的内容替换，不能完全代表真实三维遮挡和时相变化。

### B4. 标签规则

定义：

- `positive_mask`：确定存在有效对应；
- `negative_mask`：确定不存在对应；
- `ignore_mask`：不确定、遮挡边缘或几何边界。

三者互斥，且覆盖所有 1024 个查询。

对 MATCH 查询提供精确目标坐标；对 NO_MATCH 查询，不生成坐标回归标签。

对于 16×16 的 D16 网格支持区域，要考虑单元尺度与变换后的覆盖范围，不能只根据中心像素生成过度确定的边界标签。

### B5. 数据隔离

按母图或地理块划分训练、校准和评价集合，不能在划分后再生成裁剪对。

建议比例：

- 训练：80% 母图；
- 校准：10% 母图；
- 独立评价：10% 母图。

使用固定随机种子 42，并保存母图 ID、裁剪参数、重叠率、旋转角、遮挡区域及生成版本。

此前已用于模型选择的封存测试，不作为新的未见数据反复调参。

## 5. 阶段 C：实现显式查询级 No-Match 决策

### C1. 第一版结构

保持 U0 所有原有参数不变。

在全局匹配概率得到之后，增加独立的查询级分类头：

\[
p_i^{nm}=\sigma(g(z_i))
\]

其中 \(p_i^{nm}\) 表示查询 \(i\) 不存在对应的预测概率。

建议输入特征：

\[
z_i=
[f_i^A,\ P_{dust},\ m_i,\ s_{max},\ \Delta s,\ \mathcal H(P_i)]
\]

分别为：

- MVT 的 A 图查询特征；
- 原 Dustbin 概率；
- 原 Matchability；
- 最大空间相似度；
- Top-1 与 Top-2 相似度差；
- 空间概率分布熵。

所有输入在第一轮训练中停止梯度。

### C2. 分类头结构

采用轻量两层 MLP：

```python
Linear(input_dim, 128)
LayerNorm(128)
GELU()
Linear(128, 1)
```

输出查询级 No-Match Logit。

不增加 Transformer、不引入 Sinkhorn，也不改原 Decoder。

**这一版本是独立的显式拒配分支，不直接替换原 1024+1 Softmax 中的 Dustbin Logit。**

这样可以保护已经验证过的 U0 坐标预测。

### C3. 输出逻辑

设预测的 No-Match 概率为 \(p_i^{nm}\)。

使用校准得到的两个阈值：

\[
\operatorname{state}_i=
\begin{cases}
\mathrm{MATCH},&p_i^{nm}\le t_{low}\\
\mathrm{NO\_MATCH},&p_i^{nm}\ge t_{high}\\
\mathrm{UNCERTAIN},&\text{其他}
\end{cases}
\]

其中：

\[
t_{low}<t_{high}
\]

阈值必须由校准集确定，不在独立评价集上调整。

MATCH 只代表存在对应的决策被接受，并不自动证明预测坐标一定准确。

### C4. 条件式输出接口

新增独立接口，不覆盖原有 U0 输出：

```python
{
    "state": ...,               # [B, 32, 32]
    "no_match_prob": ...,       # [B, 1, 32, 32]
    "source_xy": ...,           # [K, 2]
    "target_xy": ...,           # [K, 2]
    "flow_xy": ...,             # [K, 2]
    "accepted_indices": ...,   # [K]
}
```

仅 MATCH 查询出现在 `source_xy`、`target_xy` 和 `flow_xy` 中。

NO_MATCH、UNCERTAIN 不发布有效目标坐标。

原稠密坐标张量可以保留为内部诊断结果，但不能将其中的任意坐标作为已接受匹配。

本阶段不要求减少 Decoder FLOPs，因为原 Decoder 可能依赖完整空间特征。真正的计算级条件解码作为后续独立研究。

## 6. 损失设计

### C1. No-Match 分类损失

仅在具有精确状态标签的位置监督：

\[
\mathcal L_{nm}
=
-\frac{1}{|N|}
\sum_{i\in N}\log p_i^{nm}
\]

\[
\mathcal L_{match}
=
-\frac{1}{|V|}
\sum_{i\in V}\log(1-p_i^{nm})
\]

总分类损失：

\[
\boxed{
\mathcal L_{exist}
=
\lambda_n\mathcal L_{nm}
+\lambda_p\mathcal L_{match}
}
\]

初始取 \(\lambda_n=\lambda_p=1\)。

正负样本分别归一化，避免不同重叠率造成类别数量差异。

UNKNOWN 查询不计算损失。

### C2. 坐标损失

第一轮冻结 U0，因此不新增坐标回归损失，也不修改 U0 原监督。

现有坐标网络始终不更新。

这样能够明确判断：

**在不改变定位能力的情况下，是否可以新增有效 No-Match 决策。**

### C3. 不采用的损失

第一轮不加入：

- Forward–Backward Cycle Loss；
- 全区域平滑正则；
- 杭州近似 H 推导的无对应 BCE；
- 高 EPE 点直接转 Dustbin 的伪标签；
- D8/D2/QRRU Loss。

避免把定位错误、真实无对应和模型不确定性混成同一个监督目标。

## 7. 训练实验矩阵

### 7.1 基线

| 实验 | 模型 | 训练 | 目的 |
|---|---|---|---|
| A0 | 原 U0 Dustbin | 否 | 检查现有拒配能力 |
| A1 | 原 U0 Matchability | 否 | 当前最强轻量基线 |
| A2 | 原有两种信号的校准组合 | 否 | 判断是否确实需要新增参数 |

三个基线使用同一数据、同样的有效点误拒约束。

### 7.2 新实验

| 实验 | 模型结构 | 训练数据 | 训练参数 |
|---|---|---|---|
| T1 | 冻结 U0 + 独立 No-Match MLP | 精确部分重叠 | 仅 MLP |
| **T2** | 冻结 U0 + 同结构 MLP | 部分重叠 + 真实纹理遮挡 | **仅 MLP** |

T1、T2：

- 相同初始化；
- 相同可训练参数量；
- 相同数据来源划分；
- 相同前向次数与优化步数；
- 相同正负样本损失定义。

区别仅在是否使用真实纹理遮挡训练信号。

不允许 T2 因增加遮挡数据而额外获得更多优化步数。

### 7.3 训练设置

初始建议：

- Optimizer：AdamW；
- 学习率：1e-3；
- Weight Decay：0.01；
- Batch Size：8，显存不足时使用累积；
- 最多 15 Epoch；
- 校准损失早停 Patience：3；
- Seed：42。

这是轻量分类头的初始配置，不直接沿用 U0 完整网络微调的训练预算。

先检查梯度确实只进入分类头，再开始训练。

第一轮不更新 MVT、MatchEmbeddingDecoder、Dustbin Embedding 或全局共享 Dustbin Logit。

## 8. 评价与验收

### 8.1 必须分别评价定位和拒配

**定位指标：**

- 原始 P@1/3/5/10；
- 原始 EPE、RMSE；
- EPE>32px；
- 接受后 P@3；
- 真实正确匹配保留率。

**拒配指标：**

- 无对应召回率；
- 有对应误拒率；
- AUROC；
- AUPRC；
- MATCH / NO_MATCH / UNCERTAIN 比例；
- 不同重叠率下的性能。

不能只报告接受后 P@3。

建议增加：

\[
R_{\mathrm{correct}@3}
=
\frac{\#\{\text{被接受且 EPE}\le3\}}
{\#\{\text{所有真实有对应查询}\}}
\]

该指标能够防止模型简单删除困难查询，从而人为提高接受后精度。

### 8.2 必须分别评价三种无对应任务

| 评价子集 | 主要指标 |
|---|---|
| 几何非重叠 | 无对应召回、误拒率 |
| 真实纹理覆盖 | 无对应召回、误拒率 |
| 杭州困难区域 | 原始参考 P@3、高置信大误差、接受覆盖率 |

不把杭州参考 EPE>32px 自动当成真实无对应。

### 8.3 建议的预设验收门槛

第一轮候选模型至少满足：

1. 在精确合成正例中，有效点误拒率 ≤1%。
2. 对纹理遮挡类无对应，召回率 ≥50%，且相比最强校准基线提高至少 15 个百分点。
3. 对几何非重叠，不能明显低于原 Matchability 的已有能力；在相同评价协议下要求不低于基线 0.5 个百分点。
4. U0 原始未筛选坐标 P@3 保持不变；若出现变化，先排查冻结和加载实现。
5. 不允许通过大面积输出 UNCERTAIN 来绕过误拒和拒配统计。
6. 在杭州困难组上，额外报告误拒与错误接受，但不使用近似 H 声称真实遮挡分类精度。

这些门槛是新实验的预设要求，不是对模型性能的保证。

### 8.4 条件式验收结论

- T2 优于 T1 与 A1：表明真实纹理遮挡监督对拒配有价值。
- T1 优于 T2：表明纹理遮挡训练可能引入额外歧义，不能盲目混训。
- 新分类头与 A1 接近：不保留新增模块。
- 只提高拒配但损失大量真实对应：不保留。
- 分类成功但 G0/G3 定位仍错误：说明拒配问题与定位问题需要分别研究，不将其算成拒配失败。

## 9. 第二阶段结构改造的启动条件

仅当 T1/T2 中至少一组通过验收，才研究真正的计算级条件解码。

下一阶段才考虑：

1. 查询级 No-Match Logit 直接参与 `1024+1` 匹配分布。
2. 对 MATCH 查询归一化空间条件分布。
3. 使用支持按查询解码的新坐标头。
4. 仅对 MATCH 查询执行坐标解码和回归。
5. 与原 MatchEmbeddingDecoder 进行定位精度和计算成本对照。

不能直接修改共享 Dustbin Logit 并载入原 Decoder 权重，就认为新概率分布与原位置编码分布兼容。

如果需要替换 Decoder，必须作为独立实验，不能与 T1/T2 合并归因。
