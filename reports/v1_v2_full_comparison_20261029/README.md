## 统一评价口径

1. 使用与 V2 相同的 `GeometryPairDataset`、RGB 输入和 512×512 尺寸，相同 manifest，逐对检查 pair_id 和顺序一致。
2. 两者最多输出 2048 点。V1 仅将原 `max_matches=12000` 改为 2048，保留原生置信排序、互选和 QRRU；不调整粗匹配上限、置信门槛或网络权重。V2 保留原来的 128 个父点 × 16 个子点。
3. 直接复用 V2 `pair_matching.metrics.measure/totals`：P@1/3/5/10 的分母为全部输出点；不可见或无真值点不计正确，EPE 仅计算已知可见点；阈值单位为 512 原图像素。
4. 不追加 RANSAC、拒配、真值筛点或补齐输出。因两者原生选择策略不同，上限相同不代表对应点集合相同；同时报告每对输出数、正确点数、空输出对数，以及逐影像对宏平均精度（空输出记 0）。
5. 杭州只有近似 H，指标表示参考一致性。RGB512 为精确合成 H。
6. 同次 V1 前向额外记录 QRRU 前的原生 D2 输出，帮助区分细化阶段的贡献。这是诊断项，主表仍比较 V1 完整输出和 V2 正式输出。

## V1 原生 QRRU 的贡献

这是同次前向直接读取 QRRU 前后的结果，没有关闭模块再重新挑选输出。QRRU 后沿用 V1 原生越界剔除，因此前后总点数有极小差异（RGB 剔除 17 点，杭州剔除 25 点）。

|测试集|阶段|P@1|P@3|EPE|
|---|---|---:|---:|---:|
|RGB512|D2，QRRU 前|68.403%|99.818%|0.8772|
|RGB512|QRRU 后|99.625%|99.828%|0.1601|
|杭州|D2，QRRU 前|21.914%|59.044%|16.2406|
|杭州|QRRU 后|24.151%|58.491%|16.3273|

V1 中已训练好的 QRRU 对精确合成数据的亚像素细化有效：P@1 从 68.403% 提高到 99.625%，EPE 从 0.877 降到 0.160 px。不能把此前小样本重训/新链路的 QRRU 退化结论推广到 V1 正式权重。杭州则存在取舍：P@1 提高，但 P@3 从 59.044% 降到 58.491%，EPE 略增。

这项部署对照不能单独证明当前 V2 合成精度差距全部由关闭 QRRU 造成：V1 的 QRRU 前 P@3 已达到 99.818%，仍高于当前 V2 的 98.338%；两者的 H0/Flow 先验、候选、监督和训练预算都不同。本次没有为了结果修改主线或启动额外训练。
