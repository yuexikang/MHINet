## 当前代码入口

- `mhinet/v2/qrru.py`：同一递归公式用于训练和推理。训练保留所有轮次；普通推理只保存末轮，复用相邻轮的插值结果。
- `mhinet/v2/semidense.py`：按置信度分批细化，凑满有效输出预算后停止，失效点自动由后续候选补齐；越界统计在 GPU 累计，循环结束后读取；开放迭代轮数、D8 模式和细匹配相关性的精度选项。
- `mhinet/v2/coarse_matcher.py`：分块列最大值更新改为固定形状 `where`；完整支持区直接生成索引；整矩阵 mutual 路径仅计算选中位置的概率。
- `mhinet/v2/benchmark.py`：真实 512 数据模块计时、1/2/3/4 轮、Top-K、D8 模式和相关性精度对照。旧参考取 Git `7dec317`，仅用于本次比较。
- `mhinet/v2/pilot.py`：简单配置、分组采样、小规模 QRRU 训练和前后评价。保留必要的尺寸、空间切分和非有限值检查；没有代码树哈希、注册审批和全量回归测试。

推理仍默认输出最多 2048，输入 512。`max_matches` 控制 QRRU 前候选数量，和最终输出上限独立。减少轮数或提前截断可能改变精度，属于消融选项，不能称为等价优化。BF16/FP16 目前只用于 D2 相关性矩阵乘法；完整 D2 特征和归一化仍是 FP32，不能据此宣称 D2 存储减半。

提前停止利用的是：QRRU 按点独立处理且不改变置信度，所以已有足够有效输出时，低分候选不能进入最终 Top-K。它与固定截断 2048 候选不同。`qrru_early_stop=True` 默认启用，诊断模式禁用以保留全量轨迹；`qrru_processed` 和 `qrru_candidates` 分别记录实际计算与候选总数。普通模式的越界/拒绝数及 `output_before_cap` 只统计已处理部分，不能当全候选统计。

## 杭州数据与小试边界

数据目录：`/home/disk1/Data/datasets/kewei/HangZhou_cloud0_rgb_RGBMatch_v4`。现有 train 100000、val 2000、pilot 400 对，全部存储为 512。`pilot` 属于训练空间分区，不能充当独立验证集。

本次在官方 train 中按 G0–G3 各抽 16 对，共 **64 对训练**；官方 val 各抽 8 对，共 **32 对验证**。固定 seed 42，检查选中训练/验证空间块无交集，不读取两套 test。

重要数据语义：`gt_type=geo_approx`、`strict_fine_supervision=false`。H 来自地理近似，并非逐点人工精确真值。小试仅用中心位置弱监督：目标侧像素误差在 `soft_radius_B_px` 内不惩罚；容差是数据给出的启发值，不是实测误差上界。不训练 D8/D2/Flow，也不把近似参考下的 Pre@1 当真实亚像素精度。

初始权重使用旧实验 C-best；仅更新基础 QRRU。64 个真实候选（不足时由扰动样本补齐）+ 扰动中心，共最多 128 查询/对；batch 1，AdamW，LR 1e-5，**128 步**。这是训练可用性检查，不能据此决定扩大训练或证明泛化提升。检查 loss/梯度、参考 EPE、32 对固定验证集前后 Pre@1/3、有效匹配 RMSE 和至少 20 个 3px 正确点的成功率。后者不是估计单应性角点的 SR@3。

## 32 对实际推理结果

RTX 4090，C-best，512，G0–G3 各 8 对，最终上限 2048。同一完整消融轮次的结果如下：

| 路径 | 平均耗时 ms | 参考 Pre@3 | 平均 QRRU 点数 |
|---|---:|---:|---:|
| 旧实现 | 176.32 | 60.76050% | 10871 |
| 只优化循环、保持完整候选 | 154.60 | 60.76050% | 10871 |
| 分块 D8 + 满额停止 | 81.87 | 60.76050% | 2240 |
| 整矩阵 D8 + 满额停止 | 67.26 | 60.75897% | 2240 |
| 固定只留 2048 候选 | 65.34 | 60.75919% | 2048 |

分块满额停止在全部 32 对保持旧输出坐标逐值相同；固定 Top2048 则平均只返回 2046.91 对。整矩阵有浮点归约/排序差异，Pre@3 变化为 -0.00153 个百分点，不能称与分块逐值相等。整矩阵的峰值分配约 1573 MiB，分块约 1325 MiB。

单独复核满额停止时：分块 81.68 ms，整矩阵 66.57 ms；整矩阵满额停止与整矩阵完整候选的坐标、置信度在 **32/32 对逐值相同**。旧路径复测为 201.90 ms，存在明显时延波动，因此不能仅用某一次比值作稳定吞吐承诺。

D8 整矩阵将该阶段约 22 ms 降到 3.2 ms；QRRU 满额停止将实际投影/迭代约 102–129 ms 降到 16 ms。当前基础默认保留分块 FP32 + 4 轮并启用满额停止；杭州小试显式使用整矩阵 FP32 + 4 轮 + 满额停止。没有采用 BF16/FP16，当前小样本中它们没有端到端加速。

1/2/3/4 轮的参考 Pre@3 分别为 60.9680% / 60.8231% / 60.8093% / 60.7590%。当前域上多轮未必更好，值得后续检查逐轮训练目标；先不凭 32 对更改默认轮数。

原始结果目录：`outputs/mhi_v2/hangzhou_inference_adaptive_20261021`（完整消融）和 `outputs/mhi_v2/hangzhou_inference_final_20261021`（满额停止复核）。

## 128 步小试结果

已完成，64 对训练覆盖 52 个空间块，32 对验证覆盖 20 个空间块，块集合无交集。所有数据均为 `geo_approx`，目标侧训练容差约 1–3px。仅在 GPU0 运行了本次有限小试，旧长程队列仍停止。

| 固定验证集指标 | 训练前 | 训练后 |
|---|---:|---:|
| 参考 Pre@1 | 26.2772% | 26.1780% |
| 参考 Pre@3 | 60.7590% | 60.8978% |
| 有效匹配参考 RMSE（含大错位） | 45.0277 px | 45.0105 px |
| 至少 20 个 3px 正确点的比例 | 84.375% | 84.375% |
| 每对输出数量 | 2048 | 2048 |

G0/G1/G2/G3 的 Pre@3 分别从 86.865/59.296/57.367/39.508% 变为 87.872/58.728/57.642/39.349%。改进不一致，不能认为已经提升泛化。

两遍训练平均 loss 2.1597 / 2.1657，最终查询参考 EPE 3.2280 / 3.2409px。两遍的扰动随机数不同，这不是同一固定训练查询集上的误差对照；只能说当前日志未显示明确收敛。梯度全部有限，裁剪前范数最大约 17.97。真实候选平均每对 55.14 个，**8/64 对没有误差在 12px 内的可用真实候选**，需要全部用扰动样本补齐。

小试证明数据接口与训练可运行，未证明新数据上的精度收益。后续应优先：固定同一批真实候选观察 1–4 轮的改善/损伤；分开报告真实候选和扰动查询；检查 G3 大错位是否由候选生成、参考几何或时相差异引起；再选择迭代监督目标。当前不自动启动更多轮数或全量训练，也不替换 C-best。

权重：`outputs/mhi_v2/hangzhou_qrru_pilot_20261021/qrru.pt`，只含 QRRU、优化器、小试配置及步数。可在小试配置中设置 `qrru_weights` 指向该文件，在基础 checkpoint 上单独加载 QRRU。
